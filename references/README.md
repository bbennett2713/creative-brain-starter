# references/

Ads you like the LAYOUT of, sorted by format. Claude borrows the structure only, never the words, product or photos.

Where to find them, in order:
1. Your own best past ads.
2. Direct competitors (same product, same price range).
3. Nearby brands in your category.

Look in the free Meta Ad Library (facebook.com/ads/library) or Foreplay (foreplay.co) if you use it. Screenshots are fine. 1 to 3 per format is plenty to start. Not sure which folder? Drop it here and Claude will sort it.

This starter ships with no ads in it. Yours go in.

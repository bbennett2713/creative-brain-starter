# Checkpoint 6: Final project (plan the experiment)

**The idea.** Before you mix any chemicals, the experiment is planned. Most people waste ad spend by underpreparing their tests: 50 ads that each change five things at once can't tell you what worked. Launching ads and finding no winner is only a failure if the test couldn't teach you anything. So every batch is a designed experiment, and the plan comes first.

This is where the back and forth matters most.

---

## Step 1: The roadmap (into `brain/roadmap.md`)

Draft it from the whole brain. It's short:

1. **What the account looks like right now.** From `brain/account-story.md`: what's carrying it, what's rising, what's fading, and which jobs are covered (ads that grab attention, ads that explain, ads that close) and which aren't. No results yet? Say so, and read the brand from the product, reviews and references instead.
2. **What that means for what to make.** The two or three gaps or opportunities that matter most.
3. **Lanes.** A lane is a direction to test over the next few batches, with a reason behind it. Draft 3 to 5 candidates, each with its reason (point to the file it came from). Examples:
   - **Replicate a winner:** same argument, new executions (new photo, new layout, new headline), never just a color swap.
   - **One hook, many formats:** the same message across several formats, to learn which format carries it.
   - **A new persona:** a customer type the reviews show but the ads never speak to.
   - **An angle nobody's tried:** from the reviews, the product teardown, or outside reading.
   - **A wide spread of new concepts:** when there's no history yet and you need a first signal.
4. **Production plan.** How many ads each lane needs and which batch makes them.
5. **What happens next** for each lane: if it works, and if it doesn't.

**The founder's move:** they pick the lane for this batch and say why. Write their reason down.

## Step 2: The experiment card (into `output/batch-NN/plan.md`)

For the chosen lane, fill in the card. Draft it; they correct it.

| | |
|---|---|
| **Lane** | which one, and its label (for example `Lane 1 · Iteration · Angle`) |
| **What led us here** | the evidence, pointing to `account-story.md`, `voice.md`, `product.md` or `reading-list.md` |
| **Hypothesis** | "We think ___ because ___." |
| **What changes** | the one thing this test varies (the angle, the format, the persona, the hook) |
| **What stays the same** | everything else: product, offer, audience, and as much of the look as possible |
| **Is it safe?** | checked against `off-limits.md` and the facts-to-confirm list; nothing risky for the brand |
| **Why it's worth testing** | what we'd do differently if we knew the answer |
| **What it teaches us, win or lose** | both, in one line each |
| **How we'll know it's really tested** | enough ads (usually 4 to 6), launched together on the same dates (if the test compares pairs, each pair gets its own ad set; otherwise agree up front that only what Meta chooses to spend on will be readable), and read only once each version being compared has about 10 purchases (or, for attention ads, a few thousand impressions). Say it in purchases, never in dollars: how they get there is their call. |
| **Success measure** | decided now, before launch (for example: one ad reaches the account's normal cost per purchase with real spend; or the hook rate beats the current best attention ad) |
| **If it wins** | the next batch |
| **If it loses** | the next batch |
| **Founder's prediction** | which ad they think wins, and why |
| **Founder signed off** | yes / no |

**Ask before you reveal:** ask for their prediction before you say yours. At checkpoint 8, the gap between prediction and result is where the learning is.

- **Hand back:** the one-page plan, and the roadmap with this lane marked "in test".

**Done when:** `brain/roadmap.md` exists and the new `output/batch-NN/plan.md` has its Founder signed off row set to yes.

# results/

Your ad results: the same numbers you already look at. A Meta Ads Manager export at the ad level (CSV) is ideal. Screenshots work too.

How to export: Ads Manager, the Ads tab, pick the date range, then Export, "Export table data", CSV. Include Ad name, Starts, Amount spent, Purchases, Purchase value or ROAS, Impressions and Link clicks.

Claude reads these, never changes them, and never touches your ad account.
